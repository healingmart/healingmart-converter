HealingMart Converter Browser Self-Test v1.28.0 사용법

실행

1. GitHub Pages 또는 로컬 정적 서버에서 컨버터 페이지를 엽니다.
2. 브라우저 개발자 도구 콘솔을 확인합니다.
3. `HM_CONVERTER_SELF_TEST.run()`을 실행하면 다시 검사할 수 있습니다.

개수 검증 방식

Self-Test는 1,128개 같은 숫자를 기대값으로 저장하지 않습니다. 실행 시 다음 계약을 비교합니다.

- 플랫폼 원본 레지스트리 수 + 단위 원본 레지스트리 수 = 통합 카탈로그 수
- 통합 카탈로그 수 = 검색 인덱스 수 = 주소 맵 수 = 공개 매니페스트 registeredCount
- 실제 공개 항목 수 = stats.published = 공개 매니페스트 publishedCount
- 실제 준비 중 항목 수 = stats.coming = 공개 매니페스트 comingCount
- published + searchVisible 수 = stats.publishedSearchVisible = 공개 매니페스트 publishedSearchVisibleCount = publicItems() 수
- 검색 숨김 수와 신규 메타 수는 통합 데이터에서 다시 계산하여 stats와 비교

따라서 컨버터가 추가되어도 Self-Test 파일의 고정 숫자를 수정하지 않습니다.

추가 검사

- canonical ID 중복과 소문자 규칙
- 데이터·검색 인덱스·주소 맵 ID 일치
- 구 ID 호환
- `?tool=` 및 단위 `from/to` 주소
- 평방미터·㎡ 검색
- MB·Mb 대소문자 검색
- XLSX CSV 중복 숨김

자동 확장 계약 테스트는 임시 컨버터를 1개 추가하고 이 브라우저 Self-Test까지 실행합니다.
